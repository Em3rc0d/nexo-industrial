# Branding — Nexo Industrial

## Nombre

**Nexo Industrial**

## Identidad

La marca usa una **N geométrica** para representar conexión entre cuenta, ubicación y acción comercial.

Colores fuente:

- Navy: `#0E2A47`
- Teal: `#16B8A6`
- Orange accent: `#F59E42`

Fuente vectorial canónica:

`assets/branding/nexo_mark.svg`

El bootstrap Android reproduce esta misma geometría como VectorDrawable para el launcher icon.

## Reglas

- No sustituir el nombre por “Nexo” solo en el launcher/app title.
- No añadir gradientes al ícono.
- Mantener el punto naranja como acento secundario.
- El ícono no debe contener texto pequeño.
